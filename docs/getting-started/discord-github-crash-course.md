## Part 2: GitHub — From Zero to Contributing

### 2.1 Setup (One Time)
```bash
# 1. Create account: github.com → verify email
# 2. Settings → 2FA → Authenticator app
# 3. Settings → SSH keys → New → paste key

# Generate SSH key (if needed):
ssh-keygen -t ed25519 -C "your@email.com"
cat ~/.ssh/id_ed25519.pub  # copy this

# 4. Configure Git:
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
git config --global init.defaultBranch main
```

---

### 2.2 Core Mental Model
```
WORKING DIR → STAGING → LOCAL REPO → REMOTE (GitHub)
   (files)      add        commit         push
                    ▲                          │
                    │                          │
                    └──────── pull/fetch ───────┘
```

| Term | Meaning |
|------|---------|
| **Repo** | Project folder with history |
| **Commit** | Snapshot + message |
| **Branch** | Parallel timeline |
| **PR** | Propose changes to main |
| **Merge** | Combine branches |
| **Clone** | Download to your machine |
| **Push** | Upload commits |
| **Pull** | Download changes |
| **Fork** | Copy to your account |

---

### 2.3 Daily Commands

#### Start New Work:
```bash
git checkout main
git pull origin main
git checkout -b feat/short-description
# work...
git add .
git commit -m "feat: what you did

- detail 1
- detail 2

Refs: #issue"
git push origin feat/short-description
# Open PR on GitHub
```

#### Update After Feedback:
```bash
# make changes...
git add .
git commit -m "fix: address review"
git push origin feat/short-description
```

#### Sync Before New Work:
```bash
git checkout main
git pull origin main
git checkout your-branch
git merge main
```

#### Inspect:
```bash
git log --oneline -10
git diff
git diff --staged
git status
```

## Part 4: Troubleshooting

### Discord
| Problem | Fix |
|---------|-----|
| Can't hear | Voice Settings → Reset; check devices |
| Mic issues | Input Volume slider → "Let's Check" test |
| No notifications | Settings → Only @mentions; check mobile perms |
| Can't see channels | React ✅ in `#rules-and-onboarding` |
| Voice lag | Close apps, wired ethernet |

### Git/GitHub
| Problem | Fix |
|---------|-----|
| Permission denied (publickey) | `ssh -T git@github.com` → check SSH key |
| "Tell me who you are" | Set `git config --global user.name/email` |
| Merge conflict | Edit files → remove markers → `git add` → `git commit` |
| Non-fast-forward rejected | `git pull origin main` → resolve → push |
| Forgot to branch | `git stash` → `git checkout -b new` → `git stash pop` |
| Wrong commit msg | `git commit --amend` (before push) |
| Pushed wrong branch | `git push origin :wrong-branch` → push correct |

## Part 6: Club Norms

### Communication
- **Default public** — DMs only for private matters
- **Use threads** — keeps channels readable
- **Search first** — Ctrl+K before asking
- **Pin important** — right-click → Pin
- **React, don't "+1"** — 👍 ✅ 🔥 💡

### Git/GitHub
- **Branch naming:** `type/short-kebab-case` (feat/, fix/, docs/, chore/, refactor/)
- **Commits:** Conventional (`feat:`, `fix:`, `docs:`, `chore:`)
- **PR size:** Small, focused — one logical change
- **Review:** Everyone reviews; approve = "read and looks good"
- **Merge:** Squash and merge

### Voice
- **Push-to-talk default** — reduces noise
- **Mute when not speaking** — Ctrl+Shift+M
- **Screen share > describe** — show, don't tell
- **Stage for events** — hand-raise to speak
