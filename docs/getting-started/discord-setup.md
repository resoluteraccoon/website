## Step-by-Step (Copy This)

### 1. Install Discord App
- **Android:** Play Store → "Discord" → Install
- **iOS:** App Store → "Discord" → Install
- **Open app**

### 2. Create Account
- Tap **"Register"**
- **Email:** Your real email (same as GitHub ideally)
- **Username:** Professional (same as GitHub if possible)
  - Good: `miracleomokaro`, `adebayo.sec`
  - Bad: `hackerboi123`, `user_xyz`
- **Password:** Strong, unique
- **Date of birth:** Real (required)
- Tap **"Create Account"**

### 3. Verify Email
- Check email inbox
- Open email from Discord
- Tap **"Verify Email"**
- Returns to app → **Account ready!**

### 4. Enable 2FA (DO THIS NOW)
- Tap **your avatar** (bottom right) → **⚙️ Settings** (gear icon)
- **My Account** → **Enable Two-Factor Auth**
- Choose **Authenticator App** (not SMS)
- **Install:** Google Authenticator / Authy / Microsoft Authenticator
- Scan QR code → Enter 6-digit code
- **Save backup codes** (screenshot + store safe)

### 5. Join Resolute Raccoon Server
**Option A: Invite Link (Easiest)**
- Tap this link on your phone: **https://discord.gg/resoluteraccoon**
- Opens in Discord app → **"Join Server"**

**Option B: Manual**
- Tap **☰** (top left) → **+** (join server)
- **"Join a Server"** → Paste: `https://discord.gg/resoluteraccoon`
- Tap **"Join"**

### 6. Verify & Get Access
- You land in **#rules-and-onboarding**
- **Read the rules completely**
- Find the rules message → **React with ✅**
- **@Member role granted automatically**
- **@Recruit role removed**
- **All channels now visible!**

### 7. Essential Settings (30 Seconds)
**Tap your avatar (bottom right) → ⚙️ Settings:**

| Setting | Change To |
|---------|-----------|
| **Privacy & Safety** → "Allow DMs from server members" | **OFF** |
| **Privacy & Safety** → "Enable message requests" | **OFF** |
| **Notifications** → "Default notification setting" | **Only @mentions** |
| **Notifications** → Disable all sounds except @mentions | **OFF** |
| **Appearance** → Theme | **Dark** |
| **Appearance** → Message Display | **Compact** |
| **Voice & Video** → Input Mode | **Voice Activity** (or Push-to-Talk) |

### 8. Set Up Push-to-Talk (Recommended)
- **Voice & Video** → **Input Mode** → **Push to Talk**
- **Keybind** → Tap "Add a Keybind" → **Action: Push to Talk** → Press **` ` (spacebar)** or **side button**
- **Done** — Hold keybind to talk, release to mute

| Action | How |
|--------|-----|
| **Join voice** | Tap voice channel (🔊 icon) → "Join Voice" |

| **Deafen** | Tap **headphone icon** (mutes incoming too) |
| **Push-to-Talk** | Hold your keybind (spacebar/side button) |
